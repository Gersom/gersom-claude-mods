# Stack

El stack **acordado** del proyecto y lo que no se usa. No es un inventario de dependencias (eso ya está en `package.json`, `pyproject.toml`, etc.): es lo que se decidió a propósito, para que el agente no vuelva a preguntar ni cambie piezas por su cuenta. Se lee antes de agregar, cambiar o quitar una pieza.

Si el motivo viene de un debate más largo, regístralo como entrada en el tema que corresponda (ver el [índice](./README.md)) y enlázalo desde acá en vez de repetirlo.
