## 2.1.0
### Cambio 1 — Regla 5: ejemplo del título del commit en inglés
- **Tipo:** reemplazar
- **Archivo:** rules.md
- **Plantilla:** template/agents/rules.md
- **Ubicación:** Regla 5 de «Reglas por defecto»
- **Modo:** todos
- **Texto anterior:**

```
(ej. `feat(T-27): ocultar pausadas vacías`)
```

- **Texto nuevo:**

```
(ej. `feat(T-27): hide empty paused tasks`)
```

### Cambio 2 — Regla 5: los commits van siempre en inglés
- **Tipo:** reemplazar
- **Archivo:** rules.md

- **Ubicación:** Regla 5 de «Reglas por defecto»
