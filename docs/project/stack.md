# Stack

Las **decisiones** de stack que un agente no puede deducir del código ni de los archivos de dependencias (`package.json`, `pyproject.toml`, etc.): qué se eligió a propósito, por qué cuando no es la opción obvia, y qué alternativas ya se descartaron. No es un inventario de lenguajes y librerías.

---

Sin decisiones de stack definidas todavía: el repo aún no tiene código ni dependencias propias. Cuando se elija lenguaje o framework para un mod, registrarlo acá.
